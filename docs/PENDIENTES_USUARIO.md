# Pendientes de verificación

No se inventaron mediciones. Despliega por HTTPS, ejecuta PSI, Lighthouse en incógnito y DevTools Performance y registra los valores reales en el informe. Si la UPTC bloquea la consulta automatizada, guarda un índice y artículo reales como HTML en `server/test/fixtures/` para ajustar el extractor.

La visualización cartográfica con Leaflet, la descarga/almacenamiento de imágenes de noticias y la prueba E2E con Playwright requieren una iteración adicional antes de presentarlas como evidencia completa.
